# Quality Prompts

保障 AI 交付质量的提示词（Prompt）模板，约束协作流程：**先调研规划 → 再执行 → 多角色审查后交付**。

把对应模板的整段内容贴到任务描述之前/之后，即可让 AI 按固定工作流执行，避免「拿到需求直接开干、做完直接交付」带来的质量问题。

## 模板一：参考最佳实践（执行前）

> 文件：[best-practices.md](best-practices.md)

在任务描述**之前**附上这段内容，AI 会先调研该领域的最佳实践、给出执行方案和验收清单，并向你提问确认后再动手：

```
# 在执行【你的任务】之前
## 请先调研这个领域目前的最佳实践和优秀案例。
## 总结高质量结果的共同结构、评价标准、关键细节和常见失败点。然后基于调研结果，给出执行方案和验收清单
## 先不要直接开始制作，有不理解的地方用苏格拉底提问法向我发问，等方案确认再执行。
```

## 模板二：交叉验证（完成后）

> 文件：[cross-review.md](cross-review.md)

在任务描述**之后**附上这段内容，AI 会启动多个 Subagent，从需求符合度、专业质量、风险漏洞等角度交叉验证结果，多数通过才交付：

```
# 完成任务后不要直接交付，也不要只由你自己审核。
## 请根据计划启动数个Subagent，分别从需求符合度，专业质量和风险漏洞等角度检查结果。
## 每个角色必须指出具体问题和修改建议。只有多数审查通过才能交付，否则修复后重新审查。
```

两个模板可以组合使用，覆盖一个任务的完整生命周期。
