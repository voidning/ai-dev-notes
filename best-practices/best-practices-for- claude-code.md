# Best practices for Claude Code

## 给 Claude 一种验证其工作的方式

- 需求+示例+审查

- 可以给我一个测试结果（测试输出，屏幕截图等等）

## 先探索、再规划，最后编码

## 在提示中提供具体的上下文

- 限定任务范围

- 指向来源

- 参考现有模式

- 描述症状

## 提供丰富的内容

- 使用 @ 引用文件

- 直接粘贴图像

- 提供 URL

- 管道数据

- 让后 Claude 获取它需要的东西

## 通过创建 sub agent 保证 main agent 上下文窗口干净

## 让 agent 采访你

- agent 会问你可能还没有考虑过的东西，比如技术实现、UI/UX、边界情况和权衡

## 尽早且经常改正方向

- Esc: 中断会话

- Esc + Esc 或者 /rewind: 恢复到以前的对话状态或代码状态

- "撤销那个"

- /clear: 重置会话，重新开始优于反复指正。在多个任务之间可以多重置会话。

- /btw by the way: 侧边临时提问，不污染主会话
